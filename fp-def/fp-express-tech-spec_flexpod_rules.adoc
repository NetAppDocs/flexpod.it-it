= Regole FlexPod
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Il design FlexPod supporta un'architettura infrastrutturale flessibile che comprende una varietà di componenti hardware e versioni software.

Usa i set di regole come guida per costruire o assemblare una configurazione FlexPod valida. I numeri e le regole elencati in questo documento rappresentano i requisiti minimi per FlexPod e possono essere ampliati utilizzando prodotti supportati all'interno delle famiglie di prodotti incluse, secondo le esigenze dei diversi ambienti e casi d'uso.
