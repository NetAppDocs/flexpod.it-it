= NetApp ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
NetApp ONTAP software è installato su tutti i sistemi NetApp FAS, AFF e AFF All SAN Array (ASA). FlexPod è convalidato con il software ONTAP, fornendo un'architettura di storage altamente scalabile che consente operazioni senza interruzioni, aggiornamenti senza interruzioni e un'infrastruttura dati agile.

Per ulteriori informazioni su ONTAP, consulta la  https://www.netapp.com/ontap-data-management-software/["Software per la gestione dei dati ONTAP"^]pagina del prodotto.
