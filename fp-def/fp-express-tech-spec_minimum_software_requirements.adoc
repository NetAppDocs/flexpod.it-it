== Requisiti software per FlexPod Express con NetApp AFF o FAS

I requisiti software per il FlexPod Express con NetApp FAS includono:

* ONTAP 9.1 o versioni successive
* Cisco NX-OS versione 7.0(3)I6(1) o successiva
* Nella configurazione gestita da Cisco UCS, Cisco UCS Manager UCS 4.0(1b)


Tutto il software deve essere elencato e supportato nel http://mysupport.netapp.com/matrix["NetApp IMT"^]. Alcune funzionalità del software potrebbero richiedere versioni del codice più recenti rispetto ai minimi elencati nelle architetture precedenti.
