= Altri requisiti
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
I requisiti aggiuntivi per FlexPod Datacenter includono i seguenti:

* Se vuoi usare VMware ESXi come hypervisor, consulta la link:https://compatibilityguide.broadcom.com/["Guida alla compatibilità Broadcom"] per verificare che i tuoi componenti hardware e software siano supportati.
* Per una distribuzione basata su OpenShift, assicurati di avere i componenti hardware e software necessari compatibili con OpenShift. Consulta la link:https://catalog.redhat.com/en/search["OpenShift Catalogo"] per maggiori informazioni.
