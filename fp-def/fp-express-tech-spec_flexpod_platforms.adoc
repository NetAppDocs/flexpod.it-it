= Piattaforme FlexPod
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./../media/


[role="lead"]
Esistono due piattaforme FlexPod:

* *FlexPod Datacenter.* Questa piattaforma è un'infrastruttura di data center altamente scalabile, adatta per carichi di lavoro e applicazioni aziendali, virtualizzazione, VDI e cloud pubblico e privato. FlexPod Datacenter ha le proprie specifiche, che sono documentate in https://docs.netapp.com/us-en/flexpod/fp-def/dc-tech-spec_solution_overview.html["Specifiche tecniche del data center FlexPod"^].
* *FlexPod Express.* questa piattaforma è un'infrastruttura convergente compatta, destinata a uffici remoti e casi di utilizzo edge.


Questo documento fornisce le specifiche tecniche della piattaforma FlexPod Express.
