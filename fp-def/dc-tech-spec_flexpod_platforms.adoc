= Piattaforme FlexPod
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Esistono due piattaforme FlexPod:

* *FlexPod Datacenter.* Questa piattaforma è un'infrastruttura di data center altamente scalabile, adatta per carichi di lavoro e applicazioni aziendali, virtualizzazione, AI/ML, database, SAP HANA, virtual desktop infrastructure (VDI) e carichi di lavoro cloud pubblici, privati e ibridi.
* *FlexPod Express.* Questa piattaforma è un'infrastruttura convergente compatta destinata a casi d'uso in uffici remoti ed edge. FlexPod Express ha le proprie specifiche, documentate nel https://docs.netapp.com/us-en/flexpod/fp-def/fp-express-tech-spec_overview.html["Specifiche tecniche di FlexPod Express"^].


Questo documento fornisce le specifiche tecniche della piattaforma FlexPod Datacenter.
