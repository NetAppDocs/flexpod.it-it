= Conclusione
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
L'implementazione di FlexPod Edge con software-defined storage offre ai clienti un percorso pratico verso i servizi dati aziendali all'edge. L'architettura combina la piattaforma Unified Edge compatta e gestita centralmente di Cisco con i servizi dati consolidati di ONTAP, abilitando lo storage software-defined all'interno di un singolo chassis che può supportare carichi di lavoro locali dove i dati vengono creati e manipolati.
